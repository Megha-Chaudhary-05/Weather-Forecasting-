# Weather Forecasting System

## Overview
This project uses historical weather data and machine learning models to predict future weather conditions such as temperature, humidity, and wind speed. The goal is to provide accurate short-term weather forecasts for better planning and decision-making.

## Features
- Analyze historical weather patterns
- Visualization of forecast trends
- User interface for entering forecast date and location
- Streamlit-based frontend (optional)

## Tech Stack
- **Language**: Python  
- **Libraries**: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn   
- **Data**: Historical weather data (2014–2017, Delhi)
